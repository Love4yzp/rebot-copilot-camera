# 时间轴编辑器

交互约束的唯一家。概念在 [`ARCHITECTURE.md`](./ARCHITECTURE.md) / [`CONTEXT.md`](../CONTEXT.md)，这里只写时间轴怎么长、怎么行为。

---

## 一句话

**这台机器剪的是物理时间。** 用户编排的不是视频片段，是臂在物理空间里的时间。剪出来的「成片」是臂的一次真实执行。

## 时间轴模型

### 骨架块与块内标记

```
骨架层(板)    保持块 ── 过渡块 ── 保持块 ── 过渡块 ── 保持块
                ▏◉   ⏸   ◉▏          ▏◉··········■▏
细节层(钉子)   快门@2s 等待@3s 快门@4s    开录@起点   停录@终点
```

- **骨架块承载结构**：被拖动、修剪、整体重排。保持块 / 过渡块交替排列。
- **事件标记承载动作**：被点、微调、删除。钉在父块内部的时间位置上，**随父块移动与修剪**。

动作不是块：脱钩在这台机器上是物理事故。标记挂父块让脱钩结构上不可能，与「`ActionContext` 里没有 arm 句柄」同一手法。

### 五条物理规则

1. **过渡块自动生成、不可删除、只可编辑。** 两个不同位姿的保持块相邻，臂必须物理地过去。相同位姿相邻则不生成过渡块。
2. **事件标记可以钉在过渡块内部任意比例处。** 用劈开过渡块来表达中点 = 捏造一个从未示教过的姿态，禁止。
3. **位姿链接式复用。** 保持块只存位姿名，不存关节角。覆盖保存或删除一个被 N 条序列链接的位姿时，必须先告知。
4. **时间尺是计划尺，播放头走真实。** 块长度是指令时长；动作执行时长是预估（半透明跨度）；等待标记是开放式。执行时块可以被现实撑长。
5. **执行中时间轴锁定，停止才解锁。** 预演不受限。

## 预演与执行：两个动词

不共用一个按钮：

- **预演**：播放头走计划尺，监视器按时间轴播模拟姿态，**臂一动不动**。全界面灰阶 —— 预演不是机器状态。预演是计划路径，真臂走上游 `move_to` 的实际路径，两者应接近、不保证一致。
- **执行**：真臂跑。播放头走真实进度，监视器翻为实况，琥珀色点亮。

**进站是计划尺之外的第一段运动**:序列从臂此刻的物理位置开始,而臂可以在工作空间任何地方。三条规矩:
- **预演从臂的当前位姿起播**:先匀速插值「当前 → 首站」这一段(时长镜像后端进站公式 `max(2.0s, 1.5 × 最大关节差 / 0.25 rad/s)` —— 1.5 是 EASE_PEAK,压住 smoothstep 缓动的峰值速度,见 `arm/base.py`),播完播放头才走上计划尺。前摇期间预演按钮显示「接近起点…」。
- **执行按距离分级**:臂离首站超过 ~0.3 rad(~17°)时,「执行」按钮换成「去起点」—— 先一次限速 goto 到首站(进站路径同样过碰撞预检),到位停住后「执行」才回来。近时一键执行不变。
- **进站对执行界面可见**:executor 的 `approaching` 标志(保持块到位计时开始前为真)让走带条显示「接近起点…」,而不是假装已在保持。

- 预演从臂的当前位姿起播，先插值「当前 → 首站」（时长镜像后端 `max(2.0s, 最大关节差 / 0.25 rad/s)`）。
- 执行：臂离首站超过 ~0.3 rad 时，「执行」换成「去起点」；近时一键执行。
- executor 的 `approaching` 让走带条显示「接近起点…」。

等待标记对两者都生效。监视器单视图全尺寸翻转：模拟与实况永不同屏。

## 布局

```
┌────────────────────────────────────────────────────┐
│ 顶部:4px 状态光带 + 序列名                [急停]     │
├──────────────┬─────────────────────────────────────┤
│ 素材库        │ 监视器(全尺寸 3D 视图)               │
│ 位姿 | 模板   │ 预演=灰阶模拟 / 执行·空闲=实况       │
├──────────────┴─────────────────────────────────────┤
│ 走带条:[▶预演] [执行(臂会动)]   时间码 / 预估总长    │
│ 编排轨道(全宽):[站位 | 时间轴]                       │
└────────────────────────────────────────────────────┘
```

- 素材库·位姿：整张卡就是目的地（点名字，臂开过去）；底部「+ 录位姿」进示教。改名/删除在 ⋯。
- 素材库·模板：「用它」进逐站位替换向导。
- 编排轨道双密度，同一 `blocks` 模型、同一 PATCH：站档位（等宽站卡，无假比例尺）⇄ 时间轴档（成比例 + 刻度尺）。
- 急停顶条 z-index 60，见 [`AGENTS.md`](../AGENTS.md)。

点哪去哪（默认）只有监视器 + 位姿库 + 急停。剪辑模式才出时间轴。这是同一产品的使用层 / 配置层，不是场景模式切换。

## 模板

模板 = 结构配方（站位、时长、标记、过渡参数）+ 位姿槽位，**不存关节角**。实例化 = 复印 + 向导，复印即脱钩。v1 只做整条序列级模板。

## 插件的位置

动作的家是块内标记。标记参数面板仍由 provider 的 manifest 渲染。持续由设备自己维持（开录 / 停录两个标记夹住一个过渡块）。工作流线性，见 `app/backend/sequences/models.py`。契约见 [`PLUGINS.md`](./PLUGINS.md)。

**预演不是机器状态,全灰阶** —— 四色通道在预演中一个都不亮。

## 刻意不做

- 路径形态（关节空间 / 笛卡尔直线 / 弧线）：不承诺
- 真·多轨并行：砸工作流线性，急停语义与碰撞面全要重估
- 条件 / 分支规则引擎
- 模板版本 / diff / 更新通知
- 热编辑（执行中改动立即生效）

预演不是机器状态，全灰阶 —— 四色通道在预演中一个都不亮。
