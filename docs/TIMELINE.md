# 工作台与站位编排

一个工作台：位姿列表、单个只读反馈查看器、序列站位编辑器。没有普通/剪辑模式、密度切换、纯浏览器预演、幽灵位姿、点击场景运动或数字键运动。

## 操作与反馈

- 点击位姿卡只选中；点击「移动到此位姿」才发起 goto。录制入口是「+ 录位姿」。
- 「＋追加」把位姿链接加入当前序列。站卡可调整顺序、保持时长、过渡时长和等待标记。
- 两个不同位姿的保持块相邻，自动补过渡；相同位姿相邻则无过渡。过渡不能独立删除。
- 等待标记在保持块内用秒，在过渡块内用 0..1 比例。到标记处保持并等待「继续」。
- 实际轨迹由 SDK 的受限轨迹规划生成，时长可能被安全约束拉长。保留的 easing 数据字段不是不同物理曲线的保证，界面不提供虚假的曲线选择。
- 执行期间禁止编辑。离首站超过约 0.3 rad 时先提供「去起点」。
- sim 的「执行仿真」驱动 MuJoCo；prod 的「执行（臂会动）」驱动真机。一个实例不能同时切这两条路径。

查看器只展示后端反馈，不展示浏览器推算的期望位置。可旋转/缩放/复位相机、收起窗口；这些都不改变物理状态。数据过期要标注；无反馈不能声称已到位。

「已到位」只认新执行的 done 上升沿；初次连接或新命令后重播的旧 done 不认领。新运动、进入示教、急停和断连立即清空。执行索引可能等于总块数，访问数组必须夹紧。

## 布局与状态

监视器 padding 固定 `46px 12px 12px`，不随机器状态跳动。急停顶条 z-index 60 高于所有弹层，prod 警告层低于它；Esc 保留，iframe 内也能触发。模态框应按原生键盘事件阻止冒泡，避免关弹层时误触宿主快捷键。

底盘灰阶，红只表示已急停，琥珀表示运动/可推动，绿表示明确到位并保持；白色快门状态当前未使用。选中项不用状态色。模式徽标与网络连接是不同维度。

## 位姿与模板

位姿链接式复用，删除前显示受影响序列（links 查询 + 确认）；**覆盖尚无同款拦截**——当前前端没有关节覆盖入口，风险路径不可达；哪天开出关节编辑入口，必须复用 links 确认（最好后端 PATCH joints 时也拦）。模板只含结构和 slot 占位，不含关节角；向导逐站绑定/录制，生成独立序列。没有摄影 seed，没有未安装能力的表单占位。
