方案 B · 卡片板为主 + 时间轴抽屉

示意线框图 · 被否决 —— 时间轴沦为二等公民
  • 这台机器编排的对象是「臂的时间」，时间轴是主角；把主角收进抽屉，与「剪辑软件」的定位自相矛盾。
  • 预演 / 执行时视线要在监视器和播放头之间来回；抽屉一拉起就遮住卡片板，两个高频视图被迫互斥。
  • 每核对一次「标记落在第几秒」都要先拉开抽屉 —— 高频确认动作平白多一步。

方案 C · 时间轴为主 + 素材库抽屉

示意线框图 · 被否决 —— 「拖位姿上轴」每做一次开一次抽屉
  • 「把位姿拖上时间轴」是编排的核心手势；素材库收进抽屉后，每摆一个站位都要先开一次抽屉，拖完还得关上。
  • 抽屉弹出时正好压住时间轴起点一侧 —— 拖拽做到一半，落点被抽屉遮住了。
  • 素材库从「余光可见」变成「靠记忆取用」；站位一多，反复开关比常驻栏更占屏幕时间。
